\# 東大数学攻略本



東京大学の数学入試問題を題材に、受験生が「問題の切り方」を学ぶための無料教材サイトです。



公開サイト：



https://apparkjp.github.io/todai-math-site/



\---



\## この教材の目的



東大数学では、公式や典型解法を覚えるだけではなく、問題を見たときに



\- 何を変数にするか

\- 条件をどう式や領域に変換するか

\- どの手筋から入るか

\- 最後に何を示すべきか



を判断する力が重要です。



本教材では、東大数学の過去問を「単元別」ではなく、次のような \*\*問題の切り方\*\* から整理しています。



\- 座標化

\- 1変数化

\- 領域化

\- 範囲決定

\- 微積分・面積体積・極限評価

\- 整数・合同式・場合分け

\- 確率・状態遷移・漸化式

\- 関数決定・接線条件

\- 空間図形・断面・体積

\- 対称性・変換・複素数・行列
