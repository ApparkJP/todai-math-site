# この教材について

東大数学　新解釈は、東京大学の数学入試問題を題材に、受験生が「問題の切り方」を学ぶための教材です。

単元ごとの公式暗記だけでなく、問題文を見たときに、

- 何を主役にするか
- 何を変数にするか
- 条件をどう式や領域に変換するか
- どの手筋から入るか
- どこを出口にするか

を判断できるようになることを目標にしています。

東大数学では、見た目の単元と実際に使う手筋が一致しないことがあります。

たとえば、図形問題に見えても、実際には座標化や1変数化が入口になることがあります。  
確率問題に見えても、状態遷移や漸化式を立てることが主役になることがあります。  
整数問題に見えても、合同式だけでなく、範囲の絞り込みや場合分けが重要になることがあります。

そのため、この教材では「何の単元か」よりも、「どう切るか」を重視します。

詳しい編集方針は、以下にまとめています。

- [この教材について](./about.md)

# 過去問分類に基づく章構成

この教材の章構成は、東大数学の過去問分類結果をもとに設計しています。

下のグラフでは、横軸を分野、縦軸を問題数として、年代別または年度別に積み上げ表示しています。  
分野は、総問題数が多い順に左から並べています。

## グラフの見方

- 横軸は、過去問を分類した分野です。
- 縦軸は、該当する問題数です。
- 色は、年代または年度を表します。
- 分野は、総問題数が多い順に並んでいます。
- 凡例をクリックすると、特定の年代・年度だけを表示できます。
- 棒にカーソルを合わせると、件数を確認できます。
