## この教材について

この教材は、東京大学の数学入試問題を題材に、受験生が「問題をどう切るか」を学ぶための教材です。

単元別の公式暗記ではなく、問題を見た瞬間に

- 何を変数にするか
- どの条件を式にするか
- どの手筋で処理するか
- どこを出口にするか

を考えられるようになることを目標にしています。
