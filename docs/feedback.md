# 誤植・改善報告



東大数学攻略本では、誤植・数式表示の崩れ・リンク切れ・説明の改善点などの報告を受け付けています。



教材の品質向上のため、気づいた点があれば以下のフォームからお知らせください。



- [誤植・改善報告フォーム](https://docs.google.com/forms/d/e/1FAIpQLScyD-15EMLtQOVB881OdkL53zxPTfNMB0ADAl8he2Ov41DA7A/viewform?usp=sharing&ouid=112541837105666600617)



## 報告していただけると助かる内容



- 該当ページのURL

- 該当箇所

- 誤植・表示崩れ・説明ミスの内容

- 改善案

- 任意の連絡先



## 対象例



- 誤字・脱字

- 数式表示の崩れ

- リンク切れ

- 解答や説明の誤り

- 表や見出しの崩れ

- もっと分かりやすくできそうな箇所
